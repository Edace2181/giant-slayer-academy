# AWS Certified Cloud Practitioner CLF-C02 Objective Map

**Campaign:** Giant Slayer Academy — AWS Cloud Practitioner  
**Blueprint:** AWS Certified Cloud Practitioner Exam Guide (CLF-C02)  
**Official structure:** 4 domains, 19 task statements

## World 1 — Cloud Foundations

**Official Domain 1: Cloud Concepts — 24%**

- **1.1** Define the benefits of the AWS Cloud.
- **1.2** Identify design principles of the AWS Cloud.
- **1.3** Understand the benefits of and strategies for migration to the AWS Cloud.
- **1.4** Understand concepts of cloud economics.

## World 2 — Security and Compliance

**Official Domain 2: Security and Compliance — 30%**

- **2.1** Understand the AWS shared responsibility model.
- **2.2** Understand AWS Cloud security, governance, and compliance concepts.
- **2.3** Identify AWS access management capabilities.
- **2.4** Identify components and resources for security.

## World 3 — Cloud Technology Core

**Official Domain 3: Cloud Technology and Services — 34%**

- **3.1** Define methods of deploying and operating in the AWS Cloud.
- **3.2** Define the AWS global infrastructure.
- **3.3** Identify AWS compute services.
- **3.4** Identify AWS database services.

## World 4 — Cloud Services and Integration

**Official Domain 3: Cloud Technology and Services — continued**

- **3.5** Identify AWS network services.
- **3.6** Identify AWS storage services.
- **3.7** Identify AWS artificial intelligence and machine learning services and analytics services.
- **3.8** Identify services from other in-scope AWS service categories.

## World 5 — Billing, Pricing, and Support

**Official Domain 4: Billing, Pricing, and Support — 12%**

- **4.1** Compare AWS pricing models.
- **4.2** Understand resources for billing, budget, and cost management.
- **4.3** Identify AWS technical resources and AWS Support options.

## Advanced Campaign Flow

- **World 6:** Dynamic Mixed Objective Review using all 19 Objective Sweep banks
- **World 7:** Four independently authored Captain Challenge banks
- **World 8:** Exam Chamber
- **Final Dungeon:** Six independently authored 65-question Practice Exams

The in-scope AWS service appendix defines content that may be assessed. The out-of-scope appendix prevents accidental expansion beyond CLF-C02.
