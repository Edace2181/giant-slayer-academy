## Blueprint Architecture

The official LPI blueprint contains five topic areas and nineteen objectives. Hydra Academy maps each official topic directly to one Objective Sweep world. This preserves the LPI hierarchy without forcing a CompTIA domain model onto the certification.

## Campaign Organization

- **World 1:** Topic 1 — The Linux Community and a Career in Open Source (4 objectives)
- **World 2:** Topic 2 — Finding Your Way on a Linux System (4 objectives)
- **World 3:** Topic 3 — The Power of the Command Line (3 objectives)
- **World 4:** Topic 4 — The Linux Operating System (4 objectives)
- **World 5:** Topic 5 — Security and File Permissions (4 objectives)
- **World 6:** Mixed Objective Review dynamically combines all 19 Objective Sweep banks. It has no independent question bank.
- **World 7:** Four dedicated Captain banks will integrate objectives across all five LPI topics after Objective Sweep approval.
- **World 8:** Exam Chamber transition into the Final Dungeon.
- **Final Dungeon:** Six separate Practice Exam banks. Because the official exam uses 40 questions in 60 minutes, the final production plan should use 40-question Practice Exams unless a later approved Hydra plan establishes a different training length.

## Captain Organization Recommendation

Captain production should preserve the four-mode Hydra progression while drawing scenarios across the five official LPI topics. Bank-level topic weighting should follow the official objective weights rather than forcing equal distribution. Boss Rush I should emphasize command-line foundations and direct application; Boss Rush II should combine system navigation, data handling, and operating-system concepts; Weakness Captain Rush should emphasize troubleshooting and administrative judgment; Final Captain Rush should integrate command-line, networking, users, permissions, archives, and scripting at the highest approved Linux Essentials difficulty.

## Phase 1 Content Status

All Objective Sweep, Captain, and Practice Exam banks are intentionally empty. World 6 uses only the future Objective Sweep pool and therefore has no JSON bank of its own.
